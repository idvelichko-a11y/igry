# igry

Ігри «Поле зору». Сайт: https://idvelichko-a11y.github.io/igry/

- `voleibol/` — «Агроволейбол»: волейбол на двох (онлайн із двох пристроїв, проти комп'ютера, удвох на одній клавіатурі).
- `drony/` — «Дрони над фермою»: 3D-гра, етап 1 — вільний політ.
- `lib/three.min.js` — бібліотека three.js r128 (MIT) для 3D.
- `lib/peerjs.min.js` — бібліотека PeerJS 1.5.5 (MIT) для прямого з'єднання двох браузерів.
